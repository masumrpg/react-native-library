MarkForge provides a type-safe, declarative configuration system. You can configure documents using `markforge.config.ts`, `markforge.config.json`, `markforge.config.yaml`, or directly via Markdown frontmatter.

---

## Configuration Hierarchy

MarkForge automatically discovers and resolves configuration using a strict 3-tier precedence hierarchy:

```
Markdown Frontmatter (Highest Priority)
        └── Project Config File (markforge.config.ts / .json / .yaml)
                └── Engine Default Settings (DEFAULT_CONFIG)
```

## TypeScript Config (`markforge.config.ts`)

Using `defineConfig` with TypeScript Enums provides **100% autocompletion and type-safety**:

```typescript
import {
  defineConfig,
  OutputFormat,
  Theme,
  Orientation,
  PaperSizeEnum,
  SyntaxTheme,
  WatermarkPosition,
} from "@masumdev/markforge";

export default defineConfig({
  // Target output formats
  to: [OutputFormat.DOCX, OutputFormat.PDF, OutputFormat.HTML],

  // Output directory
  outputDir: ".temp/output-full-spec",

  // Visual document theme (Theme.CORPORATE or custom ThemeProps object)
  theme: Theme.CORPORATE,

  // Page orientation & standard size
  orientation: Orientation.PORTRAIT,
  paperSize: PaperSizeEnum.A4,

  // Page margins
  margins: {
    top: "3cm",
    bottom: "2.5cm",
    left: "2.5cm",
    right: "2.5cm",
  },

  // Running headers with per-zone styling & tokens
  header: {
    left: {
      text: "{company} - {title}",
      color: "#0D998D",
      fontSize: 9,
      bold: true,
    },
    center: "Internal Technical Guide",
    right: {
      text: "v{version}",
      color: "#94A3B8",
      fontSize: 8.5,
      italic: true,
    },
    divider: true,
    dividerColor: "#CBD5E1",
  },

  // Running footers with dynamic page numbering
  footer: {
    left: {
      text: "Author: {author}",
      color: "#64748B",
      fontSize: 8.5,
    },
    center: {
      text: "{date}",
      color: "#94A3B8",
      fontSize: 8.5,
      italic: true,
    },
    right: {
      text: "Page {page} of {pages}",
      color: "#0D998D",
      fontSize: 9,
      bold: true,
    },
    divider: true,
    dividerColor: "#CBD5E1",
  },

  // Automatic Table of Contents
  toc: true,

  // Watermark configuration
  watermark: {
    text: "CONFIDENTIAL DRAFT",
    color: "#E11D48",
    opacity: 0.1,
    fontSize: 52,
    rotate: -45,
    position: WatermarkPosition.DIAGONAL,
  },

  // Syntax highlighting palette
  syntaxTheme: SyntaxTheme.DRACULA,

  // Assets & bundling flags
  embedImages: true,
  bundleHtml: true,

  // Global document metadata
  metadata: {
    title: "Unified Platform Architecture & Document Suite",
    subtitle: "Enterprise Specification & Feature Validation Guide",
    author: "Ma'sum",
    company: "Masum Dev Technologies",
    version: "1.0.0",
    date: "2026-08-29",
    lang: "en",
  },
});
```

## Per-Zone Header & Footer Customization

Each zone (`left`, `center`, `right`) can be defined either as a simple string or as a typed `HeaderFooterSlot` object with granular font, color, size, bold, and italic controls:

```typescript
header: {
  left: {
    text: "{company} - {title}",
    color: "#0D998D",
    fontSize: 9,
    fontFamily: "Inter, Segoe UI, sans-serif",
    bold: true,
  },
  right: {
    text: "v{version}",
    color: "#94A3B8",
    fontSize: 8.5,
    italic: true,
  },
  divider: true,
  dividerColor: "#CBD5E1",
}
```

| Slot Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `text` | `string` | **Required** | Template text (supports `{title}`, `{company}`, `{author}`, `{version}`, `{date}`, `{page}`, `{pages}`) |
| `color` | `string` | `"#94A3B8"` | Custom hex or named color string |
| `fontSize` | `number` | `9` | Font size in points (pt) |
| `fontFamily` | `string` | `"Segoe UI"` | Font family for this specific slot |
| `bold` | `boolean` | `false` | Whether text is bold weight |
| `italic` | `boolean` | `false` | Whether text is in italics |

## Custom Document Theming (`ThemeProps`)

In addition to `Theme.CORPORATE`, you can pass a full `ThemeProps` object to completely brand your documents:

```typescript
export default defineConfig({
  theme: {
    primaryColor: "#0D998D",
    primaryDark: "#008073",
    primaryLight: "#D9F1F0",
    backgroundColor: "#FFFFFF",
    textColor: "#0F172A",
    textMuted: "#64748B",
    borderColor: "#E2E8F0",
    cardBackground: "#F8FAFC",
    fontFamily: "'Inter', sans-serif",
    fontMono: "'Fira Code', monospace",
  },
});
```

## Dynamic Metadata Tokens

Variables defined in `metadata` or Markdown frontmatter can be referenced inside headers, footers, and templates using `{token}` syntax:

| Token | Source | Example Output |
| :--- | :--- | :--- |
| `{title}` | Document title | `Platform Reference Guide` |
| `{subtitle}` | Document subtitle | `Enterprise Architecture` |
| `{author}` | Author name | `Ma'sum` |
| `{version}` | Document version | `1.0.0` |
| `{date}` | Document date | `2026-08-29` |
| `{company}` | Company or organization | `Masum Dev Technologies` |
| `{page}` | Current page number (Footers only) | `1` |
| `{pages}` | Total pages count (Footers only) | `4` |

## Signatures & Approval Blocks (`signatures`)

Add formal corporate approval and signature sections (*Lembar Pengesahan / Tanda Tangan*) at the end of documents with support for 1 to 4 signatory slots, variable token substitution, and custom visual styling:

```typescript
export default defineConfig({
  signatures: {
    align: "space-between", // "left" | "center" | "right" | "space-between"
    style: "line",          // "line" | "box" | "clean"
    borderColor: "#CBD5E1",
    items: [
      {
        title: "Prepared by",
        name: "{author}",
        role: "Lead Platform Architect",
        date: "{date}",
      },
      {
        title: "Reviewed by",
        name: "Sarah Jenkins",
        role: "Head of Engineering",
        date: "{date}",
      },
      {
        title: "Approved by",
        name: "Dr. Alexander Wright",
        role: "Chief Technology Officer",
        date: "{date}",
      },
    ],
  },
});
```

### Signature Block Properties

| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `items` | `SignatureItem[]` | **Required** | Array of 1 to 4 signature item definitions |
| `align` | `SignatureAlign` | `"space-between"` / `"right"` | Alignment (`"left"`, `"center"`, `"right"`, `"space-between"`) |
| `style` | `SignatureStyle` | `"line"` | Visual style: `"line"` (underline divider), `"box"` (bordered card), `"clean"` (borderless) |
| `borderColor` | `string` | `"#CBD5E1"` | Color of the separator line or bounding box border |
| `titleColor` | `string` | `"#64748B"` | Color of the title label (e.g. "Prepared by") |
| `nameColor` | `string` | `"#0F172A"` | Color of the signatory name |
| `roleColor` | `string` | `"#64748B"` | Color of the role and date labels |
| `spacingBefore` | `string \| number` | `"2.5rem"` | Top spacing before the signature block |

### `SignatureItem` Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| `title` | `string` | Title or sign-off label above signature (e.g. `"Prepared by"`, `"Approved by"`) |
| `name` | `string` | Signatory person name (supports metadata tokens like `{author}`) |
| `role` | `string` | Signatory job title, role, or department (e.g. `"Lead Platform Architect"`) |
| `date` | `string \| boolean` | Date string, `{date}` token, or `true` for auto-formatted current date |
| `image` | `string` | Optional signature image path, URL, or Base64 data URI (digital seal or handwritten signature) |
| `signatureHeight` | `number \| string` | Blank height reserved for physical handwriting signature (default: `60px`) |

### Frontmatter Quick Definition

Signatures can also be defined directly inside document frontmatter:

```markdown
---
title: "Service Level Agreement"
author: "Ma'sum"
signatures:
  align: right
  style: box
  items:
    - title: "Authorized Signature"
      name: "{author}"
      role: "Lead Platform Architect"
      date: true
---
```
