You can install `@masumdev/markforge` globally as a command-line tool or locally as a project dependency.

## Global Installation (CLI)

Install globally to use the `markforge` command anywhere in your terminal:

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install -g @masumdev/markforge
    ```
  </TabItem>
  <TabItem label="bun">
    ```bash
    bun add -g @masumdev/markforge
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add -g @masumdev/markforge
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn global add @masumdev/markforge
    ```
  </TabItem>
</Tabs>

Verify your installation:

```bash
markforge --version
# Output: 0.2.1
```

---

## Local Installation (Project / Monorepo)

Install as a development dependency in your workspace:

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install -D @masumdev/markforge
    ```
  </TabItem>
  <TabItem label="bun">
    ```bash
    bun add -d @masumdev/markforge
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add -D @masumdev/markforge
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add -D @masumdev/markforge
    ```
  </TabItem>
</Tabs>

Add a script to your `package.json`:

```json
{
  "scripts": {
    "build:docs": "markforge docs/spec.md --to docx,pdf,html -o dist/docs"
  }
}
```

## PDF Requirements

PDF output is rendered via **headless Chromium**. MarkForge automatically detects the browser on your system in this order:

| Platform | Auto-detected browsers |
| :--- | :--- |
| **Linux** | `google-chrome`, `chromium`, `chromium-browser`, `microsoft-edge` |
| **macOS** | Google Chrome, Chromium, Microsoft Edge |
| **Windows** | Chrome (`%LOCALAPPDATA%` / `%PROGRAMFILES%`), **Microsoft Edge** (built-in), Chromium |

<Aside type="tip">
**Windows users**: Microsoft Edge is bundled with Windows 10/11 and is automatically detected — no additional install needed.
</Aside>

### Custom Browser Path

If your browser is installed in a non-standard location, set the `CHROME_PATH` environment variable:

```bash
# Linux / macOS
export CHROME_PATH="/usr/local/bin/chromium"

# Windows (PowerShell)
$env:CHROME_PATH = "C:\Users\YourName\AppData\Local\Google\Chrome\Application\chrome.exe"

# Or use PUPPETEER_EXECUTABLE_PATH (if you use Puppeteer)
export PUPPETEER_EXECUTABLE_PATH="/path/to/chrome"
```

<Aside type="note">
If no Chromium-based browser is found, MarkForge falls back to a minimal PDF-1.4 structure. The fallback contains the document title only — no styling, images, or full content. Install Chrome or Edge to get full PDF output.
</Aside>
