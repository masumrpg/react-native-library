You can install `@masumdev/markforge` globally as a command-line tool or locally as a project dependency.

## Global Installation (CLI)

Install globally to use the `markforge` command anywhere in your terminal:

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install -g @masumdev/markforge
    ```
  </TabItem>
  <TabItem label="bun">
    ```bash
    bun add -g @masumdev/markforge
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add -g @masumdev/markforge
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn global add @masumdev/markforge
    ```
  </TabItem>
</Tabs>

Verify your installation:

```bash
markforge --version
# Output: 0.4.0
```

---

## Local Installation (Project / Monorepo)

Install as a development dependency in your workspace:

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install -D @masumdev/markforge
    ```
  </TabItem>
  <TabItem label="bun">
    ```bash
    bun add -d @masumdev/markforge
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add -D @masumdev/markforge
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add -D @masumdev/markforge
    ```
  </TabItem>
</Tabs>

Add a script to your `package.json`:

```json
{
  "scripts": {
    "build:docs": "markforge docs/spec.md --to docx,pdf,html -o dist/docs"
  }
}
```

## PDF Requirements & Enterprise Sandboxing

PDF output is rendered via **headless Chromium**. MarkForge automatically detects the browser on your system:

| Platform | Auto-detected browsers |
| :--- | :--- |
| **Linux** | `google-chrome`, `chromium`, `chromium-browser`, `microsoft-edge`, `brave-browser` |
| **macOS** | Google Chrome, Chromium, Microsoft Edge, Brave Browser |
| **Windows** | **Microsoft Edge** (native Windows 10/11 browser), Google Chrome, Brave Browser |

<Aside type="tip">
**Enterprise & Windows Environments**: MarkForge runs headless Chromium with strict sandboxing flags (`--disable-sync`, `--no-first-run`, `--no-default-browser-check`, isolated temporary `--user-data-dir`, and zero external network font requests). On Windows, Microsoft Edge is automatically detected and prioritized.
</Aside>

### Custom Browser Path

If your browser is installed in a non-standard location, set the `CHROME_PATH` environment variable:

```bash
# Linux / macOS
export CHROME_PATH="/usr/local/bin/chromium"

# Windows (PowerShell)
$env:CHROME_PATH = "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
```
