`@masumdev/rn-tajweed-verse` is a specialized Quran verse parser and renderer for React Native and Expo applications. It automatically parses Quranic text annotated with bracket markup tags (e.g. `[q[خَلَقَ]]`) and applies color-coding, rule explanations, and interactive touch handlers.

## Features

<CardGrid>
  <Card title="15 Core Tajweed Rules" icon="open-book">
    Supports Hamzatul Wasl, Silent letters, Normal/Permissible/Necessary/Obligatory Madd, Qalqalah, Ikhfa, Iqlab, Idgham, and Ghunnah.
  </Card>
  <Card title="4 Color Theme Presets" icon="palette">
    Pre-configured theme palettes (`classic`, `dark`, `pastel`, and `accessible`) tailored for light and dark screens.
  </Card>
  <Card title="Interactive Touch Guides" icon="comment">
    Tap any color-coded word to trigger rule explanations, linguistic descriptions, and pronunciation guides.
  </Card>
  <Card title="Custom Rule Injection" icon="setting">
    Inject custom regex patterns and styling callbacks (`customRules`) alongside standard Tajweed rule definitions.
  </Card>
</CardGrid>
