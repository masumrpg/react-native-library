`@masumdev/react-native-qr-code-gen` is a vector SVG QR code generator for React Native and Expo projects. It provides built-in design presets, custom corner eye shapes, module piece styling, linear & radial gradients, center logo masking, and image background clips.

## Features

<CardGrid>
  <Card title="Vector SVG Rendering" icon="laptop">
    Renders high-resolution vector QR codes using `react-native-svg` without canvas pixelation.
  </Card>
  <Card title="Built-in Design Presets" icon="star">
    Includes pre-configured presets like `BASIC`, `HEART`, `DOT`, `TRIANGLE`, `RAIN`, `WITH_LOGO`, `LINEAR_GRADIENT`, and `RADIAL_GRADIENT`.
  </Card>
  <Card title="Custom Eye & Piece Shapes" icon="setting">
    Configure corner eye shapes (`square`, `circle`, `dot`, `triangle`, `heart`) and cell piece shapes (`square`, `dot`, `rounded`, `rain`).
  </Card>
  <Card title="Loading States & Logos" icon="rocket">
    Support center logo embedding with automatic background masking, custom loading placeholders, and clip masks.
  </Card>
</CardGrid>
