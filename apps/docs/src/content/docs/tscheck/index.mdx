`@masumdev/tscheck` is a high-performance TypeScript AST auditing CLI tool and engine. It inspects single projects or monorepos for deprecated API usages, unused variables/imports, and explicit `any` types, rendering a terminal interface powered by **Ink (React in Terminal)** with zero emojis.

## Core Capabilities

<CardGrid>
  <Card title="AST Deprecation Analysis" icon="warning">
    Detects usages of functions, methods, classes, properties, and types tagged with JSDoc `@deprecated`, displaying the deprecation reason and exact call sites.
  </Card>
  <Card title="Unused Diagnostic Scanner" icon="close">
    Analyzes TypeScript compiler diagnostics to catch unused variables, imports, parameters, and destructured items across all packages.
  </Card>
  <Card title="Strict Any-Type Policy" icon="seti:typescript">
    Flags explicit `any` type annotations, assertions (`as any`), and generic type arguments to uphold strict type safety standards.
  </Card>
  <Card title="Interactive Ink React UI" icon="laptop">
    Renders real-time scan progress with animated spinners, progress bars, and ASCII summary tables using React & Ink with a strict zero-emoji aesthetic.
  </Card>
  <Card title="JSON & YAML Config with Schema" icon="setting">
    Configure audits using `.tscheckrc.json`, `tscheck.config.json`, or `tscheck.config.yaml` with instant IDE schema autocompletion.
  </Card>
  <Card title="Interactive Live Search Dashboard" icon="magnifier">
    Launch with `tscheck -i` to filter violations, workspaces, and code issues in real-time right in your terminal.
  </Card>
</CardGrid>
