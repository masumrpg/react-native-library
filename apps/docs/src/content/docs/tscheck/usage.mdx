`@masumdev/tscheck` can be used via the command-line interface (CLI) or imported as a library in your scripts.

---

## CLI Commands & Flags

Run `tscheck` in the root of your project or monorepo:

```bash
tscheck
```

### Command-Line Flags

| Flag | Description | Default |
| :--- | :--- | :--- |
| `-c, --config <path>` | Path to custom configuration file (`.json`, `.yaml`, `.ts`) | Auto-detected |
| `-o, --output <dir>` | Custom directory to write audit reports | `.temp/tscheck` |
| `-i, --interactive` | Launch interactive terminal search dashboard with live filtering | `false` |
| `--no-deprecated` | Disable deprecated API usages check | `false` |
| `--no-unused` | Disable unused variables and imports check | `false` |
| `--no-any` | Disable explicit any usages check | `false` |
| `--fail-on-warning` | Exit with non-zero exit code if violations are found | `false` |
| `--json` | Output pure JSON to stdout without Ink UI (headless / CI) | `false` |
| `-V, --version` | Output version number | |
| `-h, --help` | Display help screen | |

## Examples

### 1. Run Audit with JSON or YAML Configuration
<Tabs>
  <TabItem label="JSON Config">
    ```bash
    # Using JSON configuration
    tscheck -c ./.tscheckrc.json
    ```
  </TabItem>
  <TabItem label="YAML Config">
    ```bash
    # Using YAML configuration
    tscheck -c ./tscheck.config.yaml
    ```
  </TabItem>
  <TabItem label="TypeScript Config">
    ```bash
    # Using TypeScript configuration
    tscheck -c ./tscheck.config.ts
    ```
  </TabItem>
</Tabs>

### 2. Interactive Search Explorer Mode (`-i`)
Launch the interactive terminal UI with live search:

```bash
tscheck -i
```
Type any package name, rule, or symbol name in the interactive text input to instantly filter audit issues in real-time.

### 3. Custom Output Directory for Reports
```bash
tscheck -o ./reports/code-audit
```

### 4. Rule-Specific Audits
```bash
# Audit only for deprecated APIs
tscheck --no-unused --no-any

# Audit only for unused variables and imports
tscheck --no-deprecated --no-any

# Audit only for explicit any types
tscheck --no-deprecated --no-unused
```

### 5. CI/CD Pipeline Mode
In CI/CD pipelines (e.g. GitHub Actions, GitLab CI), use `--fail-on-warning` to fail the build if any violations are detected:

```bash
tscheck --fail-on-warning
```

## Programmatic API

You can import `@masumdev/tscheck` into your TypeScript or JavaScript scripts:

```typescript
import { audit, writeAuditReports, defineConfig } from "@masumdev/tscheck";

// 1. Run the audit engine programmatically
const report = await audit({
  rootDir: process.cwd(),
  rules: {
    deprecated: true,
    unused: true,
    noExplicitAny: true,
  },
});

console.log(`Files Scanned: ${report.summary.filesScanned}`);
console.log(`Clean Files: ${report.summary.cleanFilesCount}`);
console.log(`Deprecated Usages: ${report.summary.totalDeprecatedUsages}`);
console.log(`Unused Identifiers: ${report.summary.totalUnusedItems}`);
console.log(`Explicit Any Usages: ${report.summary.totalAnyUsages}`);

// 2. Export reports to disk (JSON & Markdown)
const savedFiles = writeAuditReports(report, {
  reporters: {
    outputDir: ".temp/tscheck",
    json: true,
    markdown: true,
  },
});

console.log(`Reports saved to: ${savedFiles.json} and ${savedFiles.markdown}`);
```
