`@masumdev/rn-ui` is a feature-rich, high-performance UI library designed specifically for React Native and Expo monorepos. Built with pure TypeScript, design tokens, and smooth Reanimated worklets.

## Features

<CardGrid>
  <Card title="55+ Production Components" icon="laptop">
    From basic Buttons and Avatars to complex Calendars, Comboboxes, ContextMenus, and BottomSheets.
  </Card>
  <Card title="Typed Design System" icon="setting">
    Unified token system for colors, typography, spacing, radii, and component-specific theme overrides.
  </Card>
  <Card title="Dark Mode & Persistence" icon="moon">
    Built-in dark mode support with automatic system preference detection and SecureStore/AsyncStorage hydration.
  </Card>
  <Card title="Monorepo Ready" icon="rocket">
    Zero-config monorepo integration for Expo Router, React Native CLI, and Turbo repos.
  </Card>
</CardGrid>
