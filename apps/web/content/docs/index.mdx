## Quick Installation

Choose the package you need and install via package manager:

```package-install
@masumdev/rn-ui
```

```package-install
@masumdev/rn-tajweed-verse
```

```package-install
@masumdev/react-native-qr-code-gen
```

## Features

- **TypeScript First**: 100% typed props, design tokens, and hooks.
- **Expo & RN Compatible**: Built for modern Expo SDK 50+ and React Native 0.73+.
- **Pre-compiled Worklets**: Reanimated worklets are pre-compiled with `react-native-builder-bob`.
- **Accessible & Customizable**: Accessible primitives with total theme control.
