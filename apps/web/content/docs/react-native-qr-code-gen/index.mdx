`@masumdev/react-native-qr-code-gen` renders customizable vector QR codes powered by `react-native-svg`. Support eye shapes (circle, square, heart, dot), data module patterns, center logos, and pre-built design presets.

## Feature Highlights

- **Custom Eye Shapes**: Configure corner eye patterns with `square`, `circle`, `dot`, `triangle`, or `heart`.
- **Dot Patterns**: Custom shapes for internal data cells (`rounded`, `dot`, `rain`, `heart`).
- **Logo Embedding**: Overlay brand logos in the center with auto error-correction adjustment.
- **Pure SVG Rendering**: Scalable, crisp resolution at any dimension.
