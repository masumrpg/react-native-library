---
title: Installation
description: How to install @masumdev/react-native-qr-code-gen in Expo and React Native projects.
---

Install the package and `react-native-svg`:

```package-install
@masumdev/react-native-qr-code-gen react-native-svg
```

For Expo projects, `react-native-svg` is included out of the box with Expo SDK.
