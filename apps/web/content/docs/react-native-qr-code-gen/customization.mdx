## Adding a Center Logo

When embedding a logo image in the center, set `ecl="H"` for high error correction capability:

```tsx
<QRCodeGen
  value="https://github.com/masumrpg"
  size={280}
  ecl="H"
  logoOptions={{
    src: require('./assets/logo.png'),
    size: 50,
    backgroundColor: '#ffffff',
    padding: 6,
    borderRadius: 12,
  }}
/>
```
