---
title: Button
description: Interactive button component with variants, sizes, tones, shapes, loading states, and icon renderers.
---

`Button` is a flexible pressable element styled according to the active theme palette.

## Usage

```tsx
import { Button } from '@masumdev/rn-ui';

export function Example() {
  return (
    <Button
      variant="filled"
      tone="primary"
      size="md"
      onPress={() => console.log('Clicked')}
    >
      Click Me
    </Button>
  );
}
```
