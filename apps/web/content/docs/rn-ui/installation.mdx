---
title: Installation
description: How to install @masumdev/rn-ui and configure peer dependencies in React Native or Expo apps.
---

## Step 1: Install Package

Install `@masumdev/rn-ui` along with required peer dependencies using your preferred package manager:

```npm
npm i @masumdev/rn-ui react-native-reanimated react-native-gesture-handler react-native-worklets
```

If you plan to use `BottomSheet` or `Calendar`, also install:

```npm
npm i @gorhom/bottom-sheet react-native-calendars
```

## Step 2: Add Reanimated Plugin

Add `react-native-reanimated/plugin` to your project's `babel.config.js`:

```js title="babel.config.js"
module.exports = {
  presets: ['babel-preset-expo'],
  plugins: [
    // Must be listed last
    'react-native-reanimated/plugin',
  ],
};
```

<Callout type="info">
`@masumdev/rn-ui` components come pre-compiled with Reanimated worklets, but your app still needs the Reanimated Babel plugin for runtime worklet execution.
</Callout>

## Step 3: Wrap App with ThemeProvider

Wrap your root application component with `ThemeProvider`:

```tsx title="App.tsx"
import React from 'react';
import { ThemeProvider, Button, Box, Text } from '@masumdev/rn-ui';

export default function App() {
  return (
    <ThemeProvider defaultColorScheme="system">
      <Box style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
        <Text variant="title1">Welcome to @masumdev/rn-ui</Text>
        <Button tone="primary" onPress={() => console.log('Pressed')}>
          Get Started
        </Button>
      </Box>
    </ThemeProvider>
  );
}
```
