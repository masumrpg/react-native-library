## v0.1.6

- **Build Infrastructure**: Migrated build target from `tsup` to `react-native-builder-bob`.
- **Worklet Compilation**: Reanimated worklets are now pre-compiled in `lib/module` and `lib/commonjs` for flawless worklet execution.
- **Dependency Hoisting**: Centralized node_modules structure for monorepos.

## v0.1.5

- Added `BottomSheet` integration with `@gorhom/bottom-sheet`.
- Added `Calendar` component based on `react-native-calendars`.
- Added `InputOTP`, `Command`, and `ContextMenu` components.

## v0.1.0

- Initial public release with 40+ core UI components and `ThemeProvider`.
