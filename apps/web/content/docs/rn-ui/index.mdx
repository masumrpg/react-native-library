## Overview

- **55+ Production Components**: From basic `Text` and `Button` to complex `BottomSheet`, `Calendar`, `Carousel`, and `Command`.
- **Pre-compiled Worklets**: Reanimated worklets are built with `react-native-builder-bob` — zero Babel plugin configuration needed by consumers.
- **Theme Hydration**: Native scheme detection with optional persistent storage (e.g., AsyncStorage).
- **Flexible Styling**: Override any component with standard `style` and `textStyle` props.
