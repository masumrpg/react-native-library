`@masumdev/rn-tajweed-verse` parses formatted Quranic verse strings containing bracketed Tajweed markup tags (e.g. `[n[...]`, `[q[...]`) and renders color-coded text with interactive press callbacks.

## Key Features

- **20+ Supported Tajweed Rules**: Supports `ham_wasl`, `slnt`, `madda_normal`, `madda_permissible`, `madda_necessary`, `madda_obligatory`, `qlq`, `ikhf_shfw`, `ikhf`, `idghm_shfw`, `iqlb`, and more.
- **Interactive Callbacks**: Per-rule `onPress` callback returning pressed text and character index.
- **Custom Rule Styling**: Override text color or font styles per rule.
- **Pure React Native**: Built on `react-native-parsed-text` — lightweight with zero native binaries.
