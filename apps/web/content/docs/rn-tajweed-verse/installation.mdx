Install `@masumdev/rn-tajweed-verse` and `react-native-parsed-text`:

```package-install
@masumdev/rn-tajweed-verse react-native-parsed-text
```

<Callout type="info">
This package is written in pure TypeScript and JavaScript with no native iOS/Android binary code required.
</Callout>
