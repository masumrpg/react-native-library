## Custom Color Theme

Pass custom rule configurations to override default colors:

```tsx
const customTajweedConfig = {
  qlq: { style: { color: '#3182ce', fontWeight: 'bold' } },
  madda_necessary: { style: { color: '#e53e3e' } },
  ikhf: { style: { color: '#38a169' } },
};

<TajweedVerse text={verseText} config={customTajweedConfig} />
```
