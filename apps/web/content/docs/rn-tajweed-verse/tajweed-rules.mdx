## Supported Rule Keys & Tags

| Rule Key | Pattern Tag | Rule Description | Default Color |
|---|---|---|---|
| `ham_wasl` | `[h[...]` | Hamzatul Wasl (connecting hamzah) | Gray |
| `slnt` | `[s[...]`, `[l[...]` | Silent letters | Light Gray |
| `madda_normal` | `[n[...]` | Normal Prolongation (Madd Tabee'ee) | Purple |
| `madda_permissible` | `[p[...]` | Permissible Prolongation (Madd Ja'iz) | Orange |
| `madda_necessary` | `[m[...]` | Necessary Prolongation (Madd Lazim) | Red |
| `madda_obligatory` | `[o[...]` | Obligatory Prolongation (Madd Wajib) | Dark Red |
| `qlq` | `[q[...]` | Qalqalah (Echoing / Shaking sound) | Blue |
| `ikhf_shfw` | `[c[...]` | Ikhfa' Syafawi (Meem Sakinah) | Green |
| `ikhf` | `[f[...]` | Ikhfa' (Noon Sakinah & Tanween) | Light Green |
| `idghm_shfw` | `[w[...]` | Idgham Syafawi | Teal |
| `iqlb` | `[i[...]` | Iqlab (Changing sound to Meem) | Amber |
